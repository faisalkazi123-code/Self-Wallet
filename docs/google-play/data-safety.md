# Data safety form answers

Self Wallet has **no INTERNET permission**, so nothing is collected or shared by the app (Google's definitions: "collected" = transmitted off the device).

| Question | Answer |
|---|---|
| Does your app collect or share any of the required user data types? | **No** |
| Is all of the user data collected by your app encrypted in transit? | Not applicable (nothing is transmitted) – if forced to answer, **Yes** |
| Do you provide a way for users to request that their data is deleted? | **Yes** – all data is on-device; users delete it in the app or by clearing app storage/uninstalling |

Notes you can add in the description field:
- SMS messages are processed only on the device to create expense records.
- Optional backups are written by the user to a location they pick via the Android file picker (device, Google Drive, OneDrive); the app itself performs no network transfer.
